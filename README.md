| Klasör | Konu | Açıklama |
|--------|------|----------|
| `html/` | HTML | Temel HTML ödevleri |
| `bootstrap/` | Bootstrap | Bootstrap framework ödevleri |
| `javascript/` | JavaScript | JavaScript ödevleri |
| `veri-yapilari/` | Veri Yapıları | Veri yapıları çalışmaları |
| `kodluyoruz/` | Kodluyoruz | Kodluyoruz eğitimi ilk repo |
